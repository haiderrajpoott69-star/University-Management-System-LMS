LODANZA LMS is a production-ready Learning Management System built with the MERN stack (MongoDB, Express, React, Node.js).
It features JWT-based authentication with role-based access control for three user types — Admin, Teacher, and Student.

Admins manage users, departments, and view system-wide analytics with charts and announcements.
Teachers create courses, upload materials, assign and grade assignments, build interactive quizzes, and mark attendance.
Students enroll in courses, submit assignments, take quizzes, track grades, and view attendance.
